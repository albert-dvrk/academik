# Академик

Адаптивный сайт с инструментами цифрового деканата. Конкурсный прототип личного кабинета студента с вымышленными данными.

Расписание, оценки, объявления и заявки часто находятся в разных системах. «Академик» собирает их в одном кабинете, чтобы студент мог с телефона посмотреть следующую пару, проверить оценки, заказать справку или написать в поддержку.

## Возможности

- Расписание на день и неделю, зачётная и экзаменационная сессии, сравнение расписаний.
- Успеваемость по семестрам с баллами и итоговыми оценками.
- Заявки с историей статусов и перепиской, справка об обучении и выписка из зачётки в PDF.
- Уведомления, новости вуза, карта кампуса, профиль со списком группы и чаты с техподдержкой.

## Развёртывание

Демо-версия доступна по адресу [academik.dvrkkai.ru](https://academik.dvrkkai.ru/). Приложение размещено на VPS Timeweb Cloud.

- **Приложение.** Python-бэкенд и интерфейс на HTML, CSS и JavaScript находятся на сервере в `/opt/academik`. Служба `academik.service` запускает приложение через systemd.
- **HTTPS.** Caddy принимает запросы на публичном домене и передаёт их приложению на `127.0.0.1:8765`.

## База данных

- **Локальный запуск.** По умолчанию приложение использует SQLite. Файл `pulse.sqlite3` создаётся автоматически рядом с `server.py`.
- **Веб-версия.** На Timeweb приложение подключается к PostgreSQL через переменную окружения `DATABASE_URL`. База работает на том же VPS и хранит аккаунты, оценки, заявки, переписку и аватарки.
