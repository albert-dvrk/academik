# Академик

Адаптивный сайт цифрового деканата. Конкурсный прототип с вымышленными данными.

## Запуск

Из папки проекта установите зависимости командой `python -m pip install -r pulse/requirements.txt` (Python 3.12 или новее). Затем выполните `python pulse/server.py` и откройте `http://127.0.0.1:8765/`. База SQLite создаётся автоматически в папке `pulse`. Для формирования справок PDF используется Arial в Windows или DejaVu Sans в Linux.

| Студенческая почта | Демо-пароль |
|---|---|
| `sasha.demo@student.example` | `Sasha-demo-26!` |
| `misha.demo@student.example` | `Misha-demo-26!` |

Демо-аккаунты с вымышленными адресами выдаются при создании базы. В рабочей системе доступ выдаётся при создании учётной записи студента в вузе.

Расписание открывается на текущем дне. В разделе «Расписание» можно выбрать неделю или дату, посмотреть зачётную и экзаменационную недели и сравнить до шести расписаний. Колокольчик открывает раздел с переключателем между уведомлениями и новостями.

Заявки сохраняются в базе данных. Для справки об обучении демо-деканат запрашивает уточнение. После ответа справку можно скачать в PDF из раскрытой карточки. Для проверки изоляции можно открыть `/api/requests/<номер>` из разных аккаунтов.
